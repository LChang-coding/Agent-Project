# 前端精炼编辑台视觉改造设计

## 目标

把现有前端从多层大卡片堆叠，收敛为轻量、专业的编辑台界面。改造仅调整 Vue 模板的展示层级、CSS 变量和视觉动效，不修改路由、接口、Pinia Store、表单字段、事件绑定或后端协议。

## 视觉方向

采用浅色的精炼编辑台风格：暖灰背景、纸白内容面、深青色作为唯一强调色。通过更小的圆角、细分割线、紧凑间距和清晰字重建立层级，不使用大面积渐变、厚重阴影或驾驶舱式卡片。

## 页面层级

- 左侧导航保留窄栏和全部既有路由，减小悬浮提示、边框与头像区的视觉重量。
- 顶栏保留当前标题、用户身份和退出动作，压缩高度并弱化副标题。
- 通用页面改成“标题与操作条 + 内容面”两层结构。
- 表单、列表、表格和状态标签使用统一的紧凑尺寸，避免每个局部都包裹大型卡片。

## 聊天工作台

- 保留会话列固定、消息区滚动、输入区固定的现有行为。
- 会话列改为更窄的冻结列表，标题与新建操作采用单行工具栏。
- 聊天顶部的运行目标、模型和刷新动作改为紧凑控制条。
- 消息气泡减少阴影和圆角，突出内容与生成状态。
- 上下文、Token、工具、调用记录和附件仍由输入区 `+` 面板打开，但变成紧凑抽屉：使用数字摘要、细进度条、时间线式调用记录和低干扰的切换标签。
- 中文输入法、Enter 发送、Shift+Enter 换行、流式消息和会话切换逻辑保持原样。

## 其他页面

- 总览、Skill、MCP、上下文、Token、可观测性和设置页复用全局紧凑组件样式。
- 上下文和 Token 页面仍保留原路由与占位内容，但采用信息条和数据列表展示，不再形成大面积卡片墙。
- 工作流页面保持拖拽、连线、节点编辑与发布行为，只收敛画布外壳、属性面板和工具目录的视觉密度。

## 动效与可用性

- 仅保留页面入场、抽屉展开、消息进入和按钮悬浮四类低幅度 CSS 动效。
- 为 `prefers-reduced-motion` 关闭非必要动画。
- 不依赖新增动画库；继续使用 Vue `Transition`、`TransitionGroup` 与 CSS。
- 保持现有响应式断点，窄屏时避免固定栏遮挡输入区。

## 实施边界

允许修改：`ConsoleLayout.vue`、`ChatWorkspaceView.vue`、通用 `base.css`、各页面的 scoped 样式和不改变绑定关系的展示容器。

禁止修改：路由定义、Store、API 请求、DTO、后端代码、事件名称、`v-model` 字段、聊天流式处理、输入法处理和会话筛选逻辑。

## 验收

- `npm run build` 通过。
- 登录、注册、聊天、流式响应、会话切换、模型切换、工作流编辑、Skill/MCP 发布与测试入口保持可用。
- 输入区 `+` 面板仍能查看上下文、Token、工具、调用与附件占位。
- 桌面和窄屏下固定会话列、消息滚动区与输入区不互相遮挡。
