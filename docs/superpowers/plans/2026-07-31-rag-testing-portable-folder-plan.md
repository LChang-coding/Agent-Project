## 执行计划

1. 解析总账中的所有 Markdown 本地链接，盘点文件、目录和 `/tmp` 补充证据。

5. 生成证据包 README 和 SHA-256 文件清单，校验所有 Markdown 链接、文件数、字节数与抽样 hash。
6. 在本计划中追加实际操作和验收数据，仅提交计划文档；证据包位于项目 Git 仓库外。

- 复制后的文件不可反向修改原文件。
- 所有总账 Markdown 本地链接必须在证据包内解析成功。
- 不将 `codex.md` 或任何密码、token、私钥复制到证据包。
