# RAG PDF / DOCX 50 份细粒度评测报告

> 结论只来自本报告列出的正式产物和数据库回读，不使用估算值，不把失败重跑目录混入统计。

## 1. 最终结论

本轮补测已经闭环：PDF、DOCX 各 50 份，同源 50 个 SciFact 问题，分别运行 `IR_NO_CLEANER` 与 `IR_NO_STRUCTURED_CHUNKING`，每个 run 都执行 Dense、Sparse、Hybrid RRF、Hybrid RRF + Rerank 四种检索，共得到 4 个正式 run、200 次文档摄取、800 条正式查询结果。

四个 run 均满足：

- 50/50 文档完成，源文件 SHA-256 全匹配；
- 20 条 warmup 后产生 200/200 个唯一 `queryId|variant`；
- 0 最终错误、0 降级、0 空结果；
- 10 分钟瞬态重试预算已启用，实际重试 0 次、等待 0 ms；
- 数据库独立回读均为 run/document/query/aggregate/failure=`1/50/200/4/0`。

最重要的质量结论：

1. **Dense 是这个短科学摘要集上最稳的基线。** 四个 run 的 Dense Recall@10 都是 1.00，平均时延约 2.10–2.47 秒。
2. **Sparse 的瓶颈是语义/词汇错位，不是文档格式。** Recall@10 为 0.88–0.90；代表问题使用 PPAR、Th17/iTreg、NF2/LATS 等词，而金标摘要使用 RXR、TGF-β、LKB1/MARK 等间接证据，BM25 类词法信号无法稳定对齐。
3. **RRF 会把 Dense 已命中的金标挤出 Top10。** PDF/no-cleaner 的 query 914：Dense rank=1，但 Hybrid 与 Rerank 都未进 Top10；这不是解析缺字造成，而是金标缺少 Sparse 命中，双路均有分数的竞争文档在 RRF 中获得优势。
4. **Rerank 是明确的时延瓶颈。** Hybrid + Rerank 平均 9.52–12.04 秒，约为不重排 Hybrid 的 4.04–5.32 倍；Rerank 阶段自身平均 6.99–9.44 秒。它能显著改善部分头部排序，但并非每个格式/策略都提高 Recall@10。
5. **扁平切块在本数据集上更省且经常更准，但不能外推到长文档。** 它使可检索子块减少 40.9%（PDF）和 41.3%（DOCX），摄取均值降低 21.1% 和 15.3%。SciFact 文档本质是单页短摘要，结构化细切容易产生碎片；真实多页 PDF、表格和长 Word 仍需要结构化策略。
6. **PDF 解析存在可确认的字符损失。** 同一金标正文中的 `TGF-β` 在两个 PDF 策略的数据库子块中均变成 `TGF- `，而 DOCX 保留 `TGF-β`。这属于 PDF 字形/Unicode 恢复缺口，虽不是 query 560 Hybrid 失败的充分原因，但会削弱词法召回和引用原文质量。
7. **父子块是有意的双层快照，不是重复索引。** 数据库同时保存 parent/child，相同短文可能内容哈希一致；worker 只对 child 做 Embedding/Qdrant 写入，检索端还按 `content_hash` 去重。代价是额外 MySQL 存储与写入，应在容量评估中单独核算。

### 技术点增减的真实差异

- PDF 关闭结构化切块后，相对 no-cleaner：
  - 子块 `137 → 81`（-40.9%），摄取均值 `26,912 → 21,229 ms`（-21.1%）；
  - Dense Recall@1 `+.06`，MRR `+.035000`；
  - Hybrid + Rerank Recall@1 `+.12`，MRR `+.070667`，Recall@10 `.98 → 1.00`。
- DOCX 关闭结构化切块后：
  - 子块 `167 → 98`（-41.3%），摄取均值 `15,928 → 13,493 ms`（-15.3%）；
  - Dense MRR 仅 `+.001667`，基本持平；
  - Hybrid + Rerank Recall@1 `+.06`，但 Recall@10 `.98 → .96`，两个问题被移出 Top10。
- 同策略格式差异：
  - no-cleaner 下 DOCX 比 PDF 多 21.9% 子块，但摄取均值低 40.8%；
  - 两种策略的 Dense Recall@10 均无格式差异；
  - 排名差异主要出现在 Hybrid/Rerank，说明 parser 形成的标题、字符与块边界会改变双路候选的相对分数，但“块更多”不等于“召回更高”。

版面复杂度分层没有显示“复杂版面更差”：例如 DOCX/no-structured 的 Hybrid Recall@10 为 COMPLEX=1.00、MEDIUM=1.00、SIMPLE=.90，两个 Top10 失败都来自 SIMPLE。原因是这批“复杂”文档仍是确定性派生短摘要，复杂度标签主要施加版面结构，不包含真实扫描噪声；它不能覆盖真实复杂 PDF 的失败模式。

## 5. 延迟与瓶颈

| 格式 / 策略 | Dense mean / p95 | Sparse mean / p95 | Hybrid mean / p95 | Hybrid + Rerank mean / p95 | Rerank 阶段 mean |
|---|---:|---:|---:|---:|---:|
| PDF / no-cleaner | 2,474 / 3,521 | 1,917 / 2,902 | 2,623 / 3,616 | 12,043 / 23,609 | 9,444 |
| DOCX / no-cleaner | 2,262 / 3,254 | 1,798 / 2,256 | 2,355 / 3,116 | 9,518 / 13,343 | 6,993 |
| PDF / no-structured | 2,122 / 2,688 | 1,820 / 2,290 | 2,155 / 2,873 | 11,459 / 18,319 | 9,232 |
| DOCX / no-structured | 2,103 / 2,701 | 1,805 / 2,239 | 2,116 / 2,477 | 10,456 / 15,570 | 8,276 |

瓶颈按确定性排序：

1. **Reranker 网络/推理阶段**：占重排请求总时延的大头，是首要优化目标。建议先做小模型/量化模型 A/B、候选数从 10 向 6–8 自适应收缩、批处理和按置信度跳过，而不是先增加线程。
2. **PDF 摄取**：同策略显著慢于 DOCX，说明解析服务/格式转换而非 Embedding 数量是主要格式成本。应把 parser、IR 构建、artifact persist、embedding、vector upsert 的分阶段时间直接写入 benchmark 结果，再用真实阶段 p95 定位。
3. **结构化子块数量**：短摘要上多约 69 个 DOCX 子块或 56 个 PDF 子块，没有换来 Dense Recall@10 提升，却增加 Embedding/Qdrant 数量。建议基于文档长度和结构密度做策略路由：短单页文档采用较粗块，长文档/表格文档保留结构切块。
4. **父子快照存储**：数据库实际保存 parent 和 child；短文 parent/child 可能内容完全相同。它不会被重复向量化，但会增加 MySQL 行数和写入。可在不破坏 parent expansion 的前提下，为“parent 与唯一 child 内容相同”的短文采用引用式 parent 或仅存一次正文。

本轮没有同步采集 CPU、内存、网络、容器资源时间序列，因此不能声称 CPU 或内存是瓶颈，也不以事后 Grafana 样本冒充同窗口数据。

## 6. 失败案例与因果链

### Case A：query 914，RRF 把 Dense 第一名挤出 Top10

- 问题：`PPAR-RXRs can be activated by PPAR ligands.`
- 金标：`3203590`，*Unique response pathways are established by allosteric interactions among nuclear hormone receptors*
- 原文件：[PDF](evaluation-data/pdf-docx-50/prepared/pdf/067-scifact-3203590.pdf) / [DOCX](evaluation-data/pdf-docx-50/prepared/docx/067-scifact-3203590.docx)
- 实际金标子块开头：`Heterodimerization is a common paradigm ... The 9-cis retinoic acid receptor (RXR) serves as ...`
- 排名：

| 配置 | Dense | Sparse | Hybrid | Hybrid + Rerank |
|---|---:|---:|---:|---:|
| PDF / no-cleaner | 1 | 未进 Top10 | 未进 Top10 | 未进 Top10 |
| DOCX / no-cleaner | 1 | 未进 Top10 | 2 | 1 |
| PDF / no-structured | 1 | 未进 Top10 | 9 | 1 |
| DOCX / no-structured | 1 | 未进 Top10 | 7 | 1 |

因果判断：金标摘要没有出现 `PPAR` 或 `PPAR ligand`，只出现 RXR 与其他核受体，Sparse 四次都失败；Dense 能识别语义关系并排第一。RRF 中同时获得 Dense/Sparse 分数的竞争文档会超过只有 Dense 强信号的金标。PDF/no-cleaner 的 Hybrid 前五名是 PTEN、biofilm autoimmunity、cholesterol、chemokine、GLP-1R 文档，说明融合被共享词法/通用生物医学信号带偏。Rerank 只能重排送入的候选；该配置下金标没有进入可重排 Top10，因此无法救回。扁平块或 DOCX 改变候选相对分数后，金标进入候选，Rerank 才恢复到第一。

可执行改进：给 RRF 增加“单路极高置信度保护”，例如 Dense rank=1 且与第二名有足够 margin 时保证进入 rerank pool；将 fusionTopK 与 rerankTopK 解耦，融合先保留 20–30 个再重排 10 个。

### Case B：query 560，DOCX 扁平块的融合退化

- 问题：`Immune responses result in the development of inflammatory Th17 cells and anti-inflammatory iTregs.`
- 金标：`40096222`，*Compromised intestinal epithelial barrier induces adaptive immune compensation that protects from colitis.*
- 原文件：[PDF](evaluation-data/pdf-docx-50/prepared/pdf/011-scifact-40096222.pdf) / [DOCX](evaluation-data/pdf-docx-50/prepared/docx/011-scifact-40096222.docx)
- 金标子块真实片段：`... a protective role for TGF-β-producing CD4(+) T cells ...`
- 数据库字符核验：DOCX 两策略保留 `TGF-β`；PDF 两策略变成 `TGF- `。
- 排名：

| 配置 | Dense | Sparse | Hybrid | Hybrid + Rerank |
|---|---:|---:|---:|---:|
| PDF / no-cleaner | 4 | 未进 Top10 | 7 | 6 |
| DOCX / no-cleaner | 4 | 未进 Top10 | 8 | 7 |
| PDF / no-structured | 3 | 未进 Top10 | 7 | 5 |
| DOCX / no-structured | 3 | 未进 Top10 | 未进 Top10 | 未进 Top10 |

因果判断：问题中的 `Th17/iTregs` 不在摘要中，金标用 `TGF-β-producing CD4(+) T cells` 间接表达保护性免疫，因此 Sparse 全部失败。DOCX/no-structured 的 Dense 仍为第 3，证明正文存在、解析成功、向量可召回；失败发生在融合阶段，不是解析或 Dense 阶段。该配置的融合前五名集中于 immune、CD4、autoimmune 等同时具备词法与语义信号的文档，金标只有单路强信号，被挤出候选；Rerank 无法处理未进入输入池的文档。PDF 丢失 β 是独立解析缺口，但 PDF Hybrid 仍命中，所以不能把这次 DOCX 失败归因于 β 字符。

可执行改进：保留每路最低配额（如 Dense Top5 + Sparse Top5 后再 RRF），不要让另一检索路完全淘汰 Dense 高排名；诊断产物应持久化每路 rank/score、fusion score 和 rerank input。

### Case C：query 830，格式改变 Hybrid 候选

- 问题：`NF2 (Merlin) causes phosphorylation and subsequent cytoplasmic sequestration of YAP in Drosophila by activating LATS1/2 kinases.`
- 金标：`1897324`，*A genetic screen identifies an LKB1–MARK signalling axis controlling the Hippo–YAP pathway*
- 原文件：[PDF](evaluation-data/pdf-docx-50/prepared/pdf/026-scifact-1897324.pdf) / [DOCX](evaluation-data/pdf-docx-50/prepared/docx/026-scifact-1897324.docx)
- 实际金标子块开头：`The Hippo–YAP pathway is an emerging signalling cascade ... One of the hits, LKB1 ...`
- 排名：

| 配置 | Dense | Sparse | Hybrid | Hybrid + Rerank |
|---|---:|---:|---:|---:|
| PDF / no-cleaner | 1 | 未进 Top10 | 8 | 1 |
| DOCX / no-cleaner | 1 | 未进 Top10 | 未进 Top10 | 未进 Top10 |
| PDF / no-structured | 1 | 未进 Top10 | 10 | 1 |
| DOCX / no-structured | 1 | 未进 Top10 | 未进 Top10 | 未进 Top10 |

因果判断：问题的 NF2/Merlin/LATS1/2 与摘要的 LKB1/MARK/Scribble 词面差距大，仅 YAP/Hippo 接近，所以 Sparse 四次失败而 Dense 四次第一。DOCX 的 Hybrid 候选被 “death”、PTEN、fibrosis、HNF4A、IL-12/IFN-γ 等双路文档占据，金标未进入 rerank input。由于 PDF 与 DOCX 的规范正文相同，差异来自 parser 形成的标题/Unicode/embedding text 及其造成的候选分数微变；现有历史审计表只持久化最终 citation 和阶段耗时，没有保存未命中金标的完整逐阶段分数，因此不能进一步声称某一个字符或某一具体分值是唯一原因。

可执行改进：对 benchmark 模式持久化受控的 TopK 诊断快照；生产默认只保存 hash/排名和有限候选，避免日志与数据库膨胀。

## 7. 清洗/切块策略应该如何继续

当前结果支持的策略不是“一刀切关闭结构化切块”，而是按文档路由：

- 单页、正文少于约 1,500–2,000 token、无表格/列表：允许扁平或少块策略；
- 多标题、多页、表格、列表、脚注：保留 Document IR、结构边界和 parent-child；
- PDF 在进入 IR 前补 Unicode 字形恢复质量门禁，至少统计 replacement/丢失字符、连字符断词、页眉页脚重复；
- 当 parent 与唯一 child 的 `content_hash` 相同时，不重复存正文或明确标为引用关系；
- 用 query-aware 动态 fusion：Dense 高置信度保护、每路最低候选配额、扩大 fusion pool 后再收缩 rerank pool；
- Rerank 应有超时、置信度跳过和候选数自适应；当前默认全量重排的成本不划算。

## 8. 证据边界与未覆盖项

- 本报告比较的是 50 份同源配对数据；此前已经完成的 200 文档 run 未重跑，也没有与本轮 50 文档结果混算。
- 本轮可以评价解析后的文本、块数、检索质量和接口阶段时延；不能评价扫描 OCR、复杂真实表格、图片语义或长文跨节召回。
- `gold.jsonl` 提供检索证据，不提供可评分的最终生成答案，因此本轮没有编造 Faithfulness、Answer Correctness 或 Hallucination 指标。
- 历史 run 没有保存所有未入选候选的逐阶段 score；失败原因中“发生在哪一阶段”由 Dense/Sparse/Hybrid/Rerank 的真实排名交叉验证，“某个候选为何获得精确分数”保持为未知。
- 同步资源序列缺失，因此资源瓶颈只报告请求阶段计时可证明的 Rerank 和摄取差异。
